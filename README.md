# Nexgensis Product Admin Dashboard

A React + Vite Product Admin Dashboard developed for the **Nexgensis Technologies Pvt. Ltd. React Developer Assignment**.

## Tech Stack

* React 19
* Vite
* Tailwind CSS
* Axios
* React Router
* JavaScript (ES6+)
* DummyJSON API

## Setup & Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/AniketSalve2373/nexgensis-product-admin-dashboard.git
cd nexgensis-product-admin-dashboard
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

### 5. Run linting

```bash
npm run lint
```

## Completed Features

1. Admin authentication, logout and protected routes
2. Product listing with responsive design
3. Search with debounce and request cancellation
4. Category filtering
5. Sorting by price, rating and title
6. Pagination with page-size selection
7. URL-based filter, sort and pagination state
8. Product details page
9. Add product with form validation
10. Edit product with form validation
11. Delete product with confirmation modal
12. LocalStorage CRUD persistence
13. Loading, empty and error states
14. Responsive sidebar, mobile navigation and header
15. Accessibility features and error handling
